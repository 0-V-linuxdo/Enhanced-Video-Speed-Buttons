# Enhanced Video Speed Buttons

在 YouTube、Bilibili、Vimeo 视频标题上方添加可点击的倍速按钮，支持键盘快捷键、按视频记忆倍速、按频道默认倍速、中英文界面和设置导入导出。

- 脚本：[`userscript/Enhanced Video Speed Buttons.user.js`](userscript/Enhanced%20Video%20Speed%20Buttons.user.js)
- 功能规格与缺陷记录：[`docs/FEATURES.md`](docs/FEATURES.md)
- 离线验收测试：[`tests/acceptance/`](tests/acceptance/)
